# Video: "The keyboard writes its own software" (Oct 6, 2026)

Uses the hook framework: two questions in the hook, answer #1 right away, "but it's not what you think" instead of explaining, real stakes, and a new question at every generation.

## Hook (0–4 s)
VO: "You told me to let Claude control my self-typing keyboard. So now it writes its own code, types it, and runs it."
- **Question 1:** "Can it actually do it?" Answer it immediately: hard cut to solenoids typing code, with the Terminal filling up.
- **Question 2:** "But can it survive 3 generations without one mistake?" Leave it open until the end.

## "But it's not what you think" (4–10 s)
VO: "Everyone in my comments said 'just use a macro.' But this isn't a macro. A macro replays keys someone recorded. Nobody knows what this code says, not even me, until Claude writes it."

## Stakes (10–18 s)
- "One missed keypress is a syntax error, and the whole chain dies."
- "That's about 1,500 keystrokes in a row with zero mistakes, on a plate that sags in the middle."
- "And the last time I left this thing running on its own, it melted a chip." (Show the dead ULN2803A if you still have it.)

## Body: a new question every generation (18–50 s)
- On screen the whole time: `GEN 1/3` and a keystroke counter.
- Before each launch: freeze frame plus "What did Claude make it do?" Then play the result.
- Gen 1 → its new thing. "Then it wrote its own replacement."
- Gen 2 → its new thing. "One more."
- Gen 3 (the last one) → close-up as it types. "Did it make it?"

## Payoff (50–60 s)
- Gen 3's goodbye on screen. Then open gen1–gen3.py side by side: "Nobody touched these keys."
- Close with a comment prompt: "It stopped at gen 3 because I told it to. Should I take the limit off?"

## Honest notes
- If a generation fails on camera, **keep it.** "It died on keystroke 1,102" is a real stake paying off, and it sets up a sequel.
- Don't claim it's dangerous beyond what's true. Its code can't touch your files or the internet; you set it up that way. "I put it in a box" is a good line if comments ask.
